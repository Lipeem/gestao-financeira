# Código de conduta

Este é um projeto pequeno sobre um tema delicado: dinheiro da casa. Para que todo mundo se sinta à vontade para
perguntar, sugerir e corrigir:

- **Respeito acima de tudo.** Critique ideias e código, nunca pessoas. Nada de ofensa, assédio, discriminação ou
  ironia com a situação financeira de alguém.
- **Paciência com quem está começando.** Muita gente chega aqui sem saber programar, só querendo organizar as contas.
  Explique em português simples.
- **Privacidade.** Não peça nem publique dados financeiros, nomes ou links de painéis de ninguém, nem os seus.
- **Sem conselho financeiro.** Discuta a ferramenta; decisões de investimento e dívida são de cada um.

Quem não seguir estas regras pode ter comentários apagados e ser bloqueado no repositório. Para relatar um problema de
conduta, use o [relato privado do GitHub](https://github.com/Lipeem/gestao-financeira/security/advisories/new) ou
abra uma issue sem detalhes pessoais pedindo contato.
